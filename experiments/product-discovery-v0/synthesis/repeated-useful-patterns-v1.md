## Repeated mechanics

1. **Claim/evidence boundary check.** Separate a repository statement, an implemented mechanism, a planned experiment, an executed result, and an external outcome.
2. **Decision-changing uncertainty.** Ask which unknown could reverse the chosen action, not which is easiest to investigate.
3. **Alternative expansion.** Add conditional, proportional, manual, and do-nothing options.
4. **Probe contract.** Before testing, specify observations and disconfirming/ambiguous evidence.
5. **Reality boundary.** Mark facts requiring users, maintainers, matched model runs, costs, or consequential execution.
6. **Provisional disposition.** Continue/revise/discard with confidence and a next cheap test.

## Autonomy boundary

Agents can inspect repository evidence, trace contradictions, generate materially distinct options, classify uncertainty provisionally, and draft experiments. Humans/reality must supply value judgments, consequence tolerance, user behavior, maintainer actionability, and blind substantive comparisons. Agents may organize that evidence but must not substitute predicted reactions.
