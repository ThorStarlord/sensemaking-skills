## 3. Exact PRNG / shuffle procedure

The canonical implementation is the Python standard library, which is
universally reproducible and needs no third-party dependency:

```python
import random

seed_int = int("0ab5cab61c1703f51f583d2ca527c9c3", 16)
cells = [("T1","R0"), ("T1","R1"), ("T1","R2"),
         ("T2","R0"), ("T2","R1"), ("T2","R2"),
         ("T3","R0"), ("T3","R1"), ("T3","R2")]

rng = random.Random(seed_int)   # Mersenne Twister, seeded by the integer
rng.shuffle(cells)              # in-place Fisher-Yates
```

This pins, unambiguously:
1. the RNG family: Python `random.Random` (Mersenne Twister);
2. the seeding convention: `Random(int(hex_seed, 16))` — the seed hex read as a
   single big-endian integer, not as raw bytes;
3. the shuffle algorithm: `random.shuffle` (Fisher-Yates) on the fixed canonical
   initial list of §1.

Rationale for this specific choice: the frozen protocol names
`seeded_fisher_yates(seed, cells)` without pinning an RNG family, seeding
convention, or implementation language. Python's `Random(int(hex,16))` +
`shuffle()` is the canonical, dependency-free reading of a hex seed string that
an independent auditor is most likely to reproduce, and it is deterministic
regardless of platform (Python guarantees the Mersenne Twister `random` module
is reproducible across versions that stabilize the algorithm). The alternative
interpretation — seeding `Random` with the 16 raw bytes — yields a different
order and is explicitly **not** selected here; selection of this one convention
and its exact result is what this addendum freezes.
