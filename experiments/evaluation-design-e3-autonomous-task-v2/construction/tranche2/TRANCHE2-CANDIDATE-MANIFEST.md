## Construction notes worth carrying forward

- **T1M-X2L** was reworked once mid-construction: its first version was a
  near-verbatim template reskin of Tranche-1's T1M-V8N (same underlying
  merge-precedence scenario). Its final, committed version uses a
  genuinely different mechanism (a single-hardcoded-lookup-path actor with
  a shared-id "distractor" that's real but irrelevant to that actor) —
  independently re-verified as structurally distinct from V8N, H2R, and
  every other T1 candidate authored in either tranche.
- **T1H-W9R** was reworded once for prose reuse (its audience-description
  paragraph had been near-verbatim copy-pasted from Tranche-1's T1H-M2X,
  despite a genuinely different underlying mechanism) — reworked in the
  implementer's own words, re-verified with unchanged oracle behavior.
- **T3M-C5N** and **T3H-N9G** both hit the same bootstrap-deadlock defect
  class that was also found and fixed in already-frozen Tranche-1 content
  (T3M-K7X/P4W/R2B — see Tranche-1's manifest correction record): a
  `proposed_direction` initial input described as "supplied up front"
  with no concrete mechanism, which genuinely fails when the literal
  commands are run. Both fixed with an explicit `--from-session
  <pre-built-dir>` bootstrap and independently re-verified end-to-end.
