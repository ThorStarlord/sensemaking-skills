## Case A — An agent narrowed the wrong target (Sensemaking, 2026-10-27)

**Source:** [Build Loop, observed repository-only discovery miss](../agents/build-loop.md#observed-repository-only-discovery-miss-2026-10-27), which describes an owner-supplied transcript at `e11a44f`; the described transcript and working-tree-only receipt were not independently reexecuted or committed to this source record. Related [November 6 source baseline](../normal-use/2026-11-06-cognitive-orientation-baseline.md).

**A.O1 — OBSERVATION, as reported:** the owner intended repository-wide analysis using the Skill as a method; the executing agent instead defined the Skill component as the target, investigated that component and stopped with a component-level `NO_FURTHER_WARRANT`. The receipt's repository identity did not match the smaller actual scope of analysis. A partial `STATUS.md` read did not cover the later current-next-step section.

**A.H1 — HYPOTHESIS:** initial task framing confused *method* with *target*. This fits the declared component responsibility and the later admission of incorrect scope; it does not prove a particular prompt-processing cause.

**A.H2 — HYPOTHESIS:** incomplete access to later repository status materially reinforced the narrow stop. The partial read supports context incompleteness; whether the missing lines would have changed the action is **UNRESOLVED**.

**A.H3 — ALTERNATIVE:** some other instruction-application or information-delivery factor contributed. No precise cause is established from these artifacts.

**A.E1 — EVIDENCE ASSESSMENT:** the observed task description is more directly related to H1 than to H2, but neither hypothesis has exclusive support; the truncated source read supports the *existence of missing context*, not the asserted effect of that miss. No numerical likelihood or ranking is warranted.

**A.Q1 — PROPOSED DISCRIMINATOR:** in a new authentic invocation, preserve the owner's full target verbatim, log actual Skill loading and complete status/source access, and inspect the agent's independently stated scope and stop rationale. A correct new run would show an effective safeguard under those conditions, **not** establish why the historical run failed. A second isolated invocation with truncated context would only be a stronger causal study if its comparison and exposure confounders were controlled; no such trial was run here.

**A.T1 — DIVERGENT HINGE, proposed:** once the target is correctly repository-wide, ask which product-level outcomes the overlooked systems could support. This is a new question suggested by the diagnostic, not a product possibility established by H1.

**Ceiling:** a real reported scope mismatch with several possible mechanisms; no unique root cause, no independent replay, no new product conclusion.

## Case B — A structural divergence rule did not distinguish meaning (Auteur, 2026-11-06)

**Source:** [Auteur Connected Creative Thread Evaluation](https://github.com/ThorStarlord/auteur/blob/d0ead25f361a071274ea8456c5947b6da902cede/docs/research/2026-11-06-connected-creative-thread-evaluation.md#4-creative-reasoning-substance-and-differentiation), and later [Creative Intention Continuity Assessment](https://github.com/ThorStarlord/auteur/blob/d0ead25f361a071274ea8456c5947b6da902cede/docs/research/2026-11-06-creative-intention-continuity-assessment.md#5-narrative-divergence-evaluation), as inspected in the target repository at `main@d0ead25f361a071274ea8456c5947b6da902cede`. These reports include a blind critic's PARTLY-RENAMED judgment and a later deterministic-rule correction; this annotation is not an additional blind review.

**B.O1 — SOURCE-REPORTED OBSERVATION:** an early Explore contract accepted different names for alternatives that partly changed only one cost-allocation variable. An independent critic found two versions partly renamed; another altered the restoration mechanism. A later pairwise-distinct-axis validator had the opposite error, rejecting two different mechanisms on the same axis; the next correction accepted such pairs but could still accept semantic renamings. These are historical behaviors of the reported code and evaluator, not universal properties of creative reasoning.

**B.H1 — HYPOTHESIS:** declared axes are a weak proxy for semantic mechanism difference. This predicts that a distinct-axis pair can still describe the same choice and a same-axis pair can be substantively different.

**B.H2 — COMPETING EXPLANATION:** the issue is only poor labels/wording; sufficiently clarified descriptions on the same axes would resolve differentiation. The source reports do not establish that labels *alone* explain every failure.

**B.E1 — GROUNDS AND LIMITS:** the reported same-axis different-mechanism and different-axis same-mechanism cases support H1 over a simplistic rule that axis difference guarantees novelty. The independent critic is meaningful *external judgment within that Auteur exercise*, not a measured truth oracle. No author study proves which alternative leads to a better story.

**B.Q1 — DISCRIMINATING QUESTION:** if two alternatives declare different axes but preserve the same decisive cause, what material reader/author outcome actually differs? If a same-axis pair changes the underlying causal mechanism and its failure conditions, does the difference survive critic review? The existing source contains illustrative answers to both; no new independent comparison is performed here.

**B.T1 — DIVERGENT HINGE, proposed:** could creative options differ by *what choice they leave the author able to make*, not just by declared narrative categories? This is a productive question, not an adopted Auteur direction or justified new graph predicate.

**Ceiling:** source-grounded critique of a semantic distinction; no proof of creativity superiority, reader effect, or general explanation cause.

## Case C — Explanatory reframing opens different product ends (Auteur, Sensemaking source use)

**Source:** [2026-11-06 Cognitive Orientation — Auteur Divergent First Use](../normal-use/2026-11-06-cognitive-orientation-auteur-divergent-first-use.md), itself a same-agent source-grounded review of Auteur `main@d0ead25f`.

**C.O1 — DOCUMENTED CURRENT BASELINE:** Auteur's development reports describe lineage of creative alternatives/intentions, read-only inquiry, and emotion/relationship anchors into Story Realization. These are reported experimental implementations, not qualified human-author experience.

**C.H1 — EXPLANATORY HYPOTHESIS, retrospective annotation:** a purely transport/retention interpretation treats the main author problem as preserving intent across subsystems. This interpretation can be useful but may not exhaust the author-valued question.

**C.H2 — ALTERNATIVE INTERPRETATION, retrospective annotation:** the more consequential author problem may be *learning from concrete story work so that the desired end or structural understanding changes*. This is a hypothetical shift in product-question framing, **not** an empirically established user need and not an explanation of a measured author outcome.

**C.T1 — SOURCE-LINKED CREATIVE TRANSFORMATIONS:** the first-use record differentiates (C1) a changed desired narrative end, (C2) deliberately preserved ambiguity, (C3) creative dissent, and (C4) bottom-up reconsideration of means while keeping the end. It also explicitly classifies a renamed relationship-timewalk as restatement.

**C.Q1 — POSSIBLE DISCRIMINATION:** have a real author perform a bounded scene-to-intention revision using current Auteur, with sources and acceptance status preserved, then observe whether a changed end/structure is actually useful or whether plain existing agent dialogue suffices. Such a human trial is **not** in the record.

**Ceiling:** sourced reasoning hypotheses and an attributed transformation account, not proof that retained knowledge improved creativity or that the new ontology generated the ideas.

## Case D — Negative/stop case: ontology versus product reality

**Source:** [Relations and Epistemics](relations-and-epistemics.md), [Cognitive Orientation Baseline](../normal-use/2026-11-06-cognitive-orientation-baseline.md), and [Divergent Exploration Ontology](divergent-exploration-ontology.md).

**D.O1 — SCOPE-LIMITED OBSERVATION:** an inspected knowledge graph or document does not record a possible product outcome.

**D.H1:** the target does not implement that outcome. **D.H2:** the inspected representation omitted it, is stale, or has not been assessed. These are alternatives, not two established facts.

**D.Q1 — TRUE DISCRIMINATOR:** search the original relevant source/implementation, governing product constraints and exact revision; the graph-only observation cannot discriminate H1 and H2.

**D.STOP:** If the task is a narrow, already-authorized validator repair and the governing owner purpose is settled, expanding into new product ends is unwarranted. "No warranted divergent output" is a valid outcome. This case is a normative boundary example, not a claim that a particular incident was run.

## What these cases establish

They show that the **existing prose/claim/hypothesis vocabulary can reconstruct** multiple explanations, each one's grounds/limitations, a counterfactual discriminator, historical reconsideration and different prospective questions. The examples also show **why a portable abductive contrast method is useful** when the agent would otherwise equate a plausible single explanation with the cause or a changed label with creative novelty.

They do **not** establish a missing machine schema field, automatic abductive inference, fresh-host loading, independent creative superiority, or a replicable causal advantage of an ontology over ordinary source reading. No new target repository or user data was mutated.
