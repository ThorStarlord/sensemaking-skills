## 1. Fit meanings and baseline

**Faithful** means the bounded representation preserves the needed distinction.
**Awkward** means the answer remains recoverable but dispersed, implicit or
manual. **Lost** requires an identified necessary distinction the examined
representation cannot preserve. **Not established** means the necessary
source, observation or review is absent. These are local qualitative review
labels, not canonical statuses or creativity scores.

The baseline documents already express questions, hypothetical futures,
source boundaries, near-duplicate judgments and changed purposes in prose.
The existing global [CQ-103..114 baseline](competency-questions.md#o-creative-prospective-discovery)
does not establish a new schema need. This implementation seeks explicit,
reusable meanings and source reconstruction; it does not manufacture an
earlier failure to justify them.

## 4. Implementation observations

The conceptual definitions and relation endpoint rules are implemented in the
linked ontology module. Record-profile, annotated-case, package-delivery,
knowledge-check/retrieval and consumer-reconstruction observations belong here
when performed; they are not established merely by this first semantic increment.

For each subsequent answer retain the exact case/record reference, fit, what
the reader recovered, whether prose/attributes were needed, and any remaining
limitation. A genuine lost meaning can warrant an extension inquiry; a
manual-but-faithful answer does not automatically require a new parser.

CQ-114 and independent-use claims remain unestablished by historical
reconstruction. The planned reference cases count as zero fresh qualification
trials. The [existing qualification readiness record](../normal-use/2026-11-04-independent-inquiry-operation-readiness.md)
continues to govern that separate inquiry.
