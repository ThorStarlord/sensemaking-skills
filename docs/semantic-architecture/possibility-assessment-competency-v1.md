## 1. Evaluation meanings and baseline

**Faithful:** the inspected material preserves the necessary distinction with attributable evidence.
**Awkward:** it is recoverable, but only through scattered prose, inferred relationships or manual source comparison.
**Lost:** the examined representation demonstrably cannot carry a required distinction.
**Not established:** relevant source/observation is unavailable or no independent consumer observation was performed.

Use these meanings to assess *representation fidelity*, not creative quality. An annotated example is evidence of documentary expressibility, not that an agent found an improved priority in normal use.

Current baselines already preserve important information in prose: the divergent ontology differentiates identity and exploratory judgment; the 2026-11-04 portfolio provides source and comparison context; the prospective ontology keeps activity/entity/decision separate. The remaining value is a shared, portable account of evaluation purposes, scoped sufficiency, methods and historical revisions. No inspected record establishes a missing executable schema as a prerequisite.
