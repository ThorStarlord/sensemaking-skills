## Program rule

Proceed autonomously with independently warranted, authorized repository work. Each stage must ground its actual consumer, evidence, authority and retained value; later stages are conditional on results, not automatically executable merely because they appear in this document. A genuine NO_CHANGE/STOP is valid. Use the existing local construction policy in CLAUDE.md, including the current prohibition on adding or manually running local unit/synthetic evidence tests; report NOT_RUN honestly while preserving hosted CI and mandatory protections.

Differentiate:
- conceptual representation from guidance delivery;
- guidance availability from use by a later actor;
- use from benefit;
- product outcome from method effectiveness;
- explanatory record from original timestamped host evidence;
- current decision authority from foreign-repository lessons.

Do not create a second controller, another Skill package, automatic cognitive router, schema or method-progress score to make AMS appear implemented.

## AMS-P3 — Diagnose inadequate method and correct proportionately

**Source owners:** existing Metareasoning/Exploration/Inquiry Policy, abductive guidance, execution/harness authority and bounded source evidence.

- [ ] Start from an actual inadequate result or repeated friction.
- [ ] If consequential, distinguish source error, flawed inference, bad question, method unsuitability, method misexecution/composition, host availability and authority blockage.
- [ ] Identify the smallest observation that would discriminate among plausible causes.
- [ ] Prefer correcting evidence/one inference/one lens before restarting an entire inquiry.

**Gate:** real inadequacy, not an invented failure scenario.

## PR and operating boundaries

Suggested PR boundary: a product-identity + discoverable-first-use slice may be one coherent PR if the diff remains narrowly reviewable. Subsequent PRs should follow independent genuine product defects or valuable responsibilities; do not open PRs solely to check milestone boxes.

Current CLAUDE.md controls branch naming, PR source/diff review, NOT_RUN local unit/synthetic tests, hosted CI and merge authorization. Integration is not evidence of independent method selection or product benefit.

## STOP / REVISIT / RECONCILE

- **ACT/BUILD:** a useful, bounded, already authorized improvement has sufficient warrant.
- **INQUIRE:** a particular unresolved source/behavioral fact would alter a consequential decision.
- **VERIFY/QUALIFY:** the claim depends on evidence current work can proportionately obtain.
- **STOP/NO_CHANGE:** existing support suffices or no genuine task/consumer is available; do not rebrand unfinished research as work.
- **REVISE/REJECT:** evidence reveals cognitive false positives, authority failures, noisy lessons or excess process costs.
- **OWNER/EXTERNAL:** only genuinely reserved authority/host blockers stop that protected action; other independent work may proceed.

**Definition of success:** users and agents can exercise AMS through the current single Skill, and genuine engineering behavior progressively justifies stronger claims that its purpose/effort/question regulation improves decisions economically. A selected product end is not a proven outcome.

product naming. The canonical Metareasoning Policy already chooses
ACT / INQUIRE / CHALLENGE / EXPLORE / VERIFY / ESCALATE / STOP, and the core

policy did not provide a compact **decision-time distinction** among an

failure; it does not establish prevalence or that this intervention fixes it.

add one **conditional purpose-fit activation cue** in using-sensemaking,
extend the existing Metareasoning Policy with source/purpose comparison,
corrective-reframe vs productive-new-question vs tangent differentiation,

source-checked SCL methodological precedent. No separate AMS Skill,
automatic router, method score, new semantic type or mandatory audit is added.

- No action preserves minimal text but leaves the owner-selected AMS
