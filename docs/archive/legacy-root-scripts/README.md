# Legacy root scripts (archived)

These files used to live at the repository root. They are early phase-era
test drivers and a spike report. Nothing in `src/`, `tests/`, CI, or
`MANIFEST.in` references them; only historical experiment evidence manifests
under `experiments/evidence/` list their old root paths (those manifests are
immutable records and were intentionally left untouched).

They are kept for provenance and are not maintained. They assume the old root
location and may not run from here.
