## Conditional methodological lesson retained from this episode

**When choosing between a convenient source/knowledge repair and a behavioral cognitive-development responsibility, verify the current construction and qualification gates separately.** A requirement for independent learning evidence or a matched comparison limits *what can be claimed*; it does not automatically exclude useful, reversible, independently warranted construction. Compare candidate responsibilities by achievable agent-facing behavior, current source/consumer, authority, cost, omission cost and genuine execution dependencies. A graph correction can still win if its value is adequate; do not infer that a more ambitious behavioral alternative is feasible merely because its specification exists.

This is a **method-selection caution**, not a global priority rule or a static instruction to refuse knowledge work. It is attributable to the current repository's owner-amended #860 contract and the PR #898 authored selection rationale. Future applicable use must check whether those conditions remain true and whether a real later task offers a different worthwhile path.

**Counterinterpretations and limits:** The alternative might remain infeasible because the current host lacks an independent executor with admissible evidence; #859's behavioral target is not already complete. PR #898's graph correction might still have been the highest-value *available* bounded responsibility. One episode does not isolate a cause of strategic convergence. The earlier selection in PR #892 is relevant context but is not independent proof of the same error.

**Revisit when:** An authentic later selection faces a method-learning construction versus qualification distinction; the Issue #860 amendment changes; or another real task shows that this caution causes needless deliberation, mistaken deferral, or a worse product outcome.
