## Governing purpose and scope

[ADR 0031](../adr/0031-persistent-semantic-stewardship.md) separates durable knowledge from agent reasoning. [ADR 0029](../adr/0029-current-product-boundary.md) excludes deterministic semantic routing and autonomous protected transitions. The current Level-3 PATH-1 construction direction in [STATUS](../../STATUS.md) is not reopened by this analysis.

The requested responsibility is to improve *application* of current reasoning meanings, particularly when local optimization prevents a materially different product-level question from being considered. No new owner-valued outcome, schema defect, or causal agent improvement is assumed.

## Warranted bounded action

Create a conceptual **crosswalk of existing meanings**, then strengthen the **portable divergent agent guide and its conditional activation** only where the existing guidance leaves the global-to-local return implicit. Keep the intervention readable and reversible. A concise operation orientation plus material-reframing prompts can provide product value without a new policy hierarchy or executable contract.

**Why not ontology expansion first?** No demonstrated necessary meaning has been lost by the Layer-2 ontology, prose, claim/hypothesis or transformation-account vocabulary. Any later truly lost distinction goes through Steward schema evolution.

**Why not an evaluation harness first?** A separate synthetic comparison cannot prove ordinary creative value, and the current decision can be advanced with narrow source guidance plus authentic-use observation.

**Stopping boundary:** close this integration work on source review and an authentic bounded outcome (or a documented blocked/negative outcome), preserving any independent-repeatability and comparative-benefit questions as open. Do not claim that this baseline proves the new guidance improves creativity.
