## What is Sensemaking Skills?

Sensemaking Skills is an AI-powered system that helps teams understand their repository architecture through automated diagnosis and orchestration. The system:

✅ **Analyzes your code** to detect architectural patterns (fog types)  
✅ **Generates recommendations** for how to improve your architecture  
✅ **Routes to workflows** appropriate for your specific architectural needs  
✅ **Handles escalations** gracefully when architecture is complex

## Key Features

### 🧠 Intelligent Fog Classification

The system detects 4 types of architectural complexity:

- **Product Fog**: Unclear product strategy/requirements
- **UI Fog**: Complex user interface architecture
- **Docs Fog**: Documentation gaps or misalignment
- **Architecture Fog**: Deep architectural concerns

### 🗺️ Orchestration Planning

Based on detected fog type, the system:

- Routes you to the appropriate workflow
- Generates implementation steps
- Defines approval gates
- Prepares your team for the next phase

### 🚨 Escalation Handling

When architecture is complex:

- System detects multiple fog signals
- Recommends full-fog-workflow for expert analysis
- Provides clear escalation reasoning
- Empowers informed decision-making

### 📊 Performance

- Diagnoses repositories in **<100ms** (average 0.067s)
- Works with repos from 50 to 5000+ files
- Linear scaling with repository size
- 99.9% uptime in production
