# Current Owner Intent: Version 1.0 Terminalization

## Primary objective

Complete the **frozen reduced-scope Version 1.0 product** and move it through
release hardening without reopening product evolution merely because another
improvement can be imagined.

## Current phase

```text
VERSION_1_TERMINALIZATION
```

The Version 1.0 product-scope obligation set is closed. Current source remains a
development predecessor of the next candidate until the separately authorized
candidate-source freeze occurs.

## Construction policy

Do not create a new Version 1.0 product capability, governance layer, taxonomy,
schema, experiment program, or strategic construction package unless positive
evidence shows that an authoritative frozen Version 1.0 obligation cannot
otherwise be satisfied.

Current-Version-1.0 work may reopen for:

- an unsatisfied frozen requirement or support-contract obligation;
- a reproducible defect that violates the frozen contract;
- incomplete required integration/reachability;
- a mandatory release-gate failure; or
- an explicit owner change to Version 1.0 scope.

The following are post-Version-1.0 opportunities by default, not blockers:

- desirable taxonomy/naming refinement;
- non-blocking documentation polish;
- speculative architecture improvement;
- new strategic hypotheses or product opportunities;
- additional experiments not required by the frozen claim;
- merely possible UX/product improvements outside the frozen contract.

## Release policy

Release-candidate qualification, exact-source freeze, merge, tagging,
publication, and final `1.0.0` advancement are downstream transitions with
their own authority and evidence requirements. Do not replace product
terminalization with repeated strategic reassessment.

## Success condition

Version 1.0 construction is complete when every obligation in the frozen scope
is satisfied and no known release-blocking defect or mandatory gate failure
contradicts that state.

```text
possible improvement != Version 1.0 blocker
NO_CHANGE + frozen scope != search for more work
version completion = closed set of obligations
```
