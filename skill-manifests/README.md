# skill-manifests/

Machine-readable contract manifests, one per Skill, consumed by
`sensemaking-skills semantic catalog|conformance`.

- Top level: engineering Skills, listed by `domain-packs/engineering.yaml`.
- `pm/`: product-management Skills, listed by
  `domain-packs/product-management.yaml` (ADR 0028).

A manifest describes a Skill's declared responsibility and artifact contracts;
it does not route work or rank Skills. Format and Domain Pack rules:
`docs/semantic-architecture/skill-contract-manifests-and-domain-packs.md`.
For a prose overview of all Skills see `docs/skill-catalogue.md`.
