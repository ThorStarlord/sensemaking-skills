# Example: Problem Frame (Vague Product Idea)

## 1. Raw Fog
"I want to build something that makes educational games feel less like digital worksheets."

## 2. Problem Under the Problem
Ludonarrative dissonance: the game mechanics don't match the learning objective, breaking the "Player Fantasy." The current GDD template lacks fields for narrative resonance.

## 3. Object Under Pressure
The GDD (Game Design Document) Template and the Player Fantasy boundary.

## 4. Failure Mode
We build "educational games" that students find boring and teachers find pedagogically shallow because the "fun" is just a wrapper, not the core mechanic.

## 5. Success Condition
A modified GDD template that mandates narrative/mechanical alignment (Explorer, Builder, Strategist tiers).

## 6. What Must Be True
- We must map BNCC objectives to specific player fantasies.
- The dev team must accept narrative constraints as part of the mechanical design.

## 7. Next Artifact
Unknowns Map

## Expected Behavior Checklist
- [x] Captures the raw "digital worksheet" fog.
- [x] Identifies ludonarrative dissonance as the root problem.
- [x] Names the GDD Template as the object under pressure.
- [x] Recommends Unknowns Map as the next artifact.
