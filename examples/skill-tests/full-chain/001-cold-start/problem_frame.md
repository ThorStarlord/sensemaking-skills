# Problem Frame

## 1. Raw Fog
"I want this repo to help me turn messy ideas into useful AI workflows."

## 2. Problem Under the Problem
The user lacks a structured bridge between unformed concepts ("messy ideas") and the specific, executable automation structures ("useful AI workflows") provided by this repository. There is a semantic gap between raw intent and repository-specific orchestration.

## 3. Object Under Pressure
`skills/workflow-orchestrator/references/workflow-registry.yaml` (The repository's orchestration registry which defines the available "useful AI workflows").

## 4. Failure Mode
The user remains stuck in the "fog" of their own ideas, unable to map their needs to the repository's capabilities, leading to tool under-utilization or incorrect manual execution of complex chains.

## 5. Success Condition
The user's "messy idea" is successfully deconstructed and mapped to a specific workflow ID in the `workflow-registry.yaml` with a clear execution plan.

## 6. What Must Be True
- The `workflow-registry.yaml` must contain a workflow entry for "sensemaking" or "problem-to-workflow" transformation.
- The repository must have a functioning `workflow-orchestrator` skill to ingest the resulting plan.
- The user must be willing to engage in a multi-step diagnostic process.
