Strategic analysis is considered premature until the foundation's coverage is
known. Expected contribution: current source-linked ownership and coverage gaps.

**Execution and return (after action):** `INSTRUCTIONS_LOADED` for
`repository-semantic-steward/SKILL.md`, followed by an applied RECALL. A manual
load is not a native invocation. A host transcript would be referenced here if
available; this fictional example has none. Recall found a current product
summary but insufficient mapping of one major system. That challenges the
assumption that the model is adequate. The controller returns to the foundation
question before deciding whether strategic exploration is warranted.

## D-002: Resolve the gap (before action)

**Evidence and uncertainty:** The earlier recall reported an unmapped system;
its relevance to the product direction cannot yet be assessed. An architecture
exploration could resolve the gap. The controller selects the Steward's
architecture procedure. Expected contribution: boundaries and owning sources.
It would reconsider broader bootstrap if the missing area proves pervasive.

**Execution and return (after action):** The native call was selected but the

would link the error, loaded files and source evidence, or mark them unavailable.
The controller incorporates the dependency and revisits possibility coverage.

## D-003: Decide whether to continue (before action)

**Evidence:** The model now covers the material systems for the requested
