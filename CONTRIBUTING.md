# Contributing to sensemaking-skills

Thank you for your interest in contributing! This document explains how to help.

## Ways to Contribute

### 1. Report Bugs
Found an issue? Help us fix it!
- Open a GitHub issue: https://github.com/ThorStarlord/sensemaking-skills/issues/new
- Include: Python version, OS, exact steps to reproduce, error message

### 2. Suggest Features
Have an idea? We'd love to hear it!
- Open a discussion
- Explain the use case and why it matters

### 3. Improve Documentation
Spotted a typo? Missing example? 
- Submit a PR with improvements

### 4. Write Code
Ready to code?
- Fork the repository
- Create a feature branch
- Write tests for new functionality
- Submit a PR

## Development Setup

```bash
git clone https://github.com/ThorStarlord/sensemaking-skills.git
cd sensemaking-skills
python -m venv .venv
source .venv/bin/activate
pip install -e .
pytest
```

## Code Style

- Python 3.11+ only
- Clear variable names
- Include docstrings
- Write tests for new features
- Follow existing patterns

## Commit Messages

Format: `type: description`
- `feat: add JSON export`
- `fix: handle empty repos`
- `docs: clarify fog types`

## Pull Requests

- Reference issues: `Fixes #123`
- Describe what and why
- Keep focused on single feature
- Be open to feedback

## Community Standards

- Be respectful and inclusive
- Assume good intent
- Help others learn
- Celebrate wins together

## Response Times

- Acknowledge issues: 24 hours
- Answer questions: 48 hours
- Review PRs: 3-5 days

## Questions?

Check the README or open a discussion.

Thank you for contributing!
