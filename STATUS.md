No deterministic `StrategicPlanner`, `OuterLoopEngine`, automatic responsibility selector, capability selector, uncertainty ranker, repository selector, workflow router, persona classifier, expertise scorer, complexity/consequentiality scorer, or automatic product-thesis revision mechanism is authorized.
- Explicit owner direction can warrant bounded repository construction; it does **not** manufacture behavioral evidence or convert missing empirical proof into PASS.
- Target rebinding verifies a caller-supplied path against already-recorded repository identity/state. `rebind valid != repository selected != work authorized`, and rebind does not bless drift.
- Cross-repository relations are explicit declarations. `relationship recorded != architectural truth`, `dependency graph valid != execution plan correct`, and `release_after != deployment authorized`.
- Completion observes terminal state rather than authoring it. `completion receipt valid != terminal decision correct`, `archive != success`, and archive does not move/delete the workspace.
- Golden paths are static navigation. `flow shown != flow recommended`, `step listed != step authorized`, and `golden path != workflow engine`.
- Multi-target verification establishes identity/current snapshot consistency only. `multi-target verified != cross-repository semantic correctness`, `same Campaign != atomic deployment unit`, and `all targets current != semantic completion`.
- Multi-Repository Campaigns do not provide cross-repository transactional commit/deploy atomicity, rollback coordination, or automatic repository discovery/scope expansion.
- Resume/profile, capability-context, preflight, Doctor, relation checking, provenance, and graph integrity establish bounded mechanical properties only; none selects a semantic next action.
- `campaign provenance` remains local rendering only. `generated provenance != published provenance != semantic correctness`.
- Additional empirical/native-harness experiments remain deferred by owner direction and are **not a prerequisite for current repository-only/hermetic construction**. Missing empirical proof remains missing.
