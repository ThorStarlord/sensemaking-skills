# Project 002: Interactive Learning Platform - Code Skills

## Raw Fog (Problem Description)

Coding bootcamps and self-taught developers face:
- High dropout rates (40-60%) due to lack of feedback
- Students don't know when they truly understand a concept
- Bootcamps can't provide 1-on-1 mentoring at scale
- Progression feels arbitrary (no clear mastery markers)
- No way to show proof of skills to employers

They need a platform that:
- Provides instant, AI-powered code review on submitted projects
- Creates adaptive learning paths based on skill level
- Generates a verifiable "skills passport" showing what was learned
- Offers spaced-repetition challenges for core concepts
- Connects students with industry mentors for live code sessions

## Target Market

- Coding bootcamps (50-500 students each)
- Self-taught developers looking for structure
- Career-switchers validating new skills
- Small dev agencies hiring junior developers

## Success Metrics (Initial Hypotheses)

- Reduce dropout rate from 50% to 20%
- Improve time-to-employment by 30%
- Help developers pass technical interviews 40% more often
- 90%+ engagement on weekly challenges
