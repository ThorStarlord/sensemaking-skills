## B. Learning & Reassessment (only after consequential new material)

**LearningAccount L1 — Previous explicit understanding:** source/actor, exact claim/assumption/lesson/dated judgment and original inspected revision.

**New material and evidence class:** source/actual revision, observed behavior or source inspection vs derived inference vs conceptual hypothesis vs actual owner decision; any contrary evidence.

**What changed (documentary lens, not schema enum):**
- [ ] **WORLD_CHANGED** — observed software/source/behavior change, exact target and evidence; no assumed user benefit.
- [ ] **UNDERSTANDING_CHANGED** — prior interpretation corrected, narrowed or reframed; original history still true in its context.
- [ ] **GOVERNING_INTENT_CHANGED** — actual owner/authority changed the goal, user or constraint; do not infer from the agent's idea.
- [ ] **No consequential difference** — state `NO_MODEL_CHANGE` / no additional account and stop.

**Delta and unaffected claims:** exact previously understood condition -> new interpretation and cited reason; originally unrelated things stay unchanged.

**Lesson applicability:** old mechanism and scope, current consumer/assumptions, contrary cases and whether to use, narrow, reject, supersede or retain the lesson. Was it only *retained* or *retrieved*, or was there an actually observed material decision application and outcome?

**Consequence for decision:** current bounded responsibility / one purpose-relative preference / canonical `strategic_reconciliation` / owner Level-4 review / new hypothetical inquiry / no change. Choose only what the evidence warrants; no automatic phase transitions.

**Stop/reopen condition and authority:** what would materially change this account and which actor owns it.

**Never infer:** a passing CI check means independent agent benefit; one local lesson is universal doctrine; changed understanding means source code changed; a creative ProductPossibility is an accepted owner thesis.

## Short illustrative NO_MODEL_CHANGE (not an observed test)

A code-reading agent finds a reference that was already packaged into the installed Skill tree. The agent updates its prior *belief* that the guidance was missing, but the file was present at the original assessed source revision, and no host invocation is observed. **UNDERSTANDING_CHANGED** for that local source claim; the accepted product goal and PATH remain intact. A concise source correction may be sufficient; no new strategic artifact or Skill change is mandatory.

## Short illustrative rejected precedent (not an observed test)

A historical `context-for` lesson relied on exact component `owned_paths`. A later repository uses a direct exhaustive source reader rather than component ownership. The later agent checks actual reader semantics, documents the lesson's inapplicability, and **does not add** a fabricated `owned_paths` or generic Memory Engine. Retaining historically accurate source evidence does not make its workaround universally applicable.
