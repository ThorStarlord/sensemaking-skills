# Possibility Assessment and Prioritization — Optional Record Template

Use only when a substantial retained assessment needs stable references. Compact prose is equally acceptable when it preserves the substantive meanings of the [portable guide](possibility-assessment-v1.md). This is **ordinary Markdown**, not a registered `artifact_id`, mandatory sidecar, executable semantic schema or validation contract. Omit irrelevant sections; leave unknowns explicit.

## Assessment and scope

**Local identity / date / author:** identify the real authoring inquiry or session; no invented reviewer.
**Responsibility and question:** coverage, marginal learning, consolidation, comparison or portfolio, with its bounded intellectual goal.
**Target(s):** original IDs with source paths and *source-file revision*. Identify the **older target baseline** inspected by an original report separately.
**Purpose and authority:** what this record can inform, what governing boundaries apply, and what it cannot authorize.

## Corpus, evidence, and frame

**Inspected corpus:** which source sets, systems, candidates, observations and existing assessments were considered. State exposure/independence constraints where relevant.
**AssessmentFrame F1 (optional local ID):** beneficiary/end, question, comparison operand type, assumptions, criteria, horizon and currentness.
**Evidence:** decisive sources and their actual claims; distinguish observations, hypotheses, inherited interpretations, counterevidence and missing evidence.

## Coverage and returns (when requested)

### CoverageFinding J1

**Dimensions examined:** declared corpus; breadth; consequence depth; empirical support; independent perspective coverage.
**Finding and sufficiency:** what is materially represented, shallow, omitted or NOT_ASSESSED; sufficient **for which subsequent purpose**, if any.
**Diminishing returns, if assessed:** separate (1) observed past repetition, (2) expected incremental learning conditional on **specific ProposedInquiryApproach M1** and (3) relative attention allocation versus named alternatives. Do not infer a measured rate from label counts.
**Reconsideration:** alternative lens/source, changed premise or observation that would change the conclusion.

## Consolidation (when requested)

### ConsolidatedView V1

**Purpose and source members:** cite original local identifiers and artifacts, not just the group name.
**Judgment J2:** restatement, variant, grouping, complement, contextual alternative or synthesis **under which criterion**; author, source/revision, basis and uncertainty.
**Preserved differences:** what is abstracted away for this view; overlapping memberships, dissent and alternative framings.
**Identity result:** explicitly state whether there is *any* independently warranted enduring `poss:`/`arch:` referent. Near duplication or grouping is never automatic sameAs.

## Comparison and priority (when requested)

### Comparison J3

**Purpose:** exploration priority / strategic attractiveness / implementation priority or another explicit comparison.
**Operands:** typed identities. For exploration, identify **InquiryQuestion Q1 + ProposedInquiryApproach M1** together; for implementation, cite independent authorization or label the comparison hypothetical.
**Criteria and reasoning:** qualitative advantages, competing arguments, relevant evidence, consequences, costs and uncertainty.
**Outcome:** preferred, tied, conditional, incomparable, unresolved or NOT_ASSESSED; use only the outcome actually warranted. If comparable, name the reversal conditions.
**Non-claims:** what the result does not establish.

## Portfolio snapshot (when requested)

### PortfolioSnapshot P1

**Frame / corpus / date:** what is being presented and compared.
**Members:** source-qualified target IDs, including retained outside-frame or unassessed entries.
**Ordering:** partial or full order only for assessed comparable entries. Preserve ties, conditional branches, limitations and explicit non-comparable/outside-frame entries.
**Portfolio effects:** complement/substitution/dependency/shared assumption only when assessed and consequential; do not promote a hypothetical causal relation to fact.

## Revision and continuation

### AssessmentRevisionAccount R1

**Predecessor:** original report/snapshot and its source-file revision.
**Changed basis:** new source, question, approach, value frame, criterion, alternative, authority or missing-evidence status.
**New bounded judgment:** how the result changes and what remains true only historically.
**Stop rationale:** what this inquiry has answered, what is NOT_ASSESSED, and what would justify another bounded responsibility. Recommendation is not action authorization.
**Persistence:** actual report location and existing session receipt reference if there is one.

## Compact illustration (not a historical repository finding)

**Question:** Which inquiry should receive attention first?
**F1:** desire to learn about a source-grounded product question using available evidence; no implementation authority implied.
**Targets:** Q1 + M1 (repeat a general conceptual explanation) and Q1 + M2 (observe an independent real episode under agreed constraints).
**J1:** M1 may have low marginal learning if that reasoning has been repeated. M2 may yield different evidence but is conditional on legitimate access and a real target. Neither has been run in this illustration.
**P1:** do not assign an unconditional common rank if M2 prerequisites are unavailable. An unresolved or outside-frame entry remains visible.
**Stop:** preserve uncertainty and grounds for future reassessment; do not start an experiment or implementation as a side effect of this record.
