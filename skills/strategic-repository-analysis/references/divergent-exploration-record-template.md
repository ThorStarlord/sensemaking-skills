# Divergent Exploration — Optional Record Template

Use this shape when a retained inquiry needs explicit references. Compact
prose is equally valid when it preserves the meanings in the
[portable guide](divergent-exploration-v1.md). Omit unused sections and fields;
leave genuine unknowns explicit. This is ordinary Markdown with no registered
`artifact_id`, required sidecar or mechanical semantic validator.

## Inquiry and scope

State the question, target and revision/source boundary, authorized outcome,
and author/date. If several questions need references, use local headings
`Q1`, `Q2` and state which inquiry they belong to.

## Sources and premises

Identify decisive original sources and what each establishes. Separate
observed source facts, governing intent, assumptions and hypotheses.
For earlier reports, distinguish the revision containing the report from
the target baseline it examined. State relevant prior-answer exposure.

## Frames and lenses

When material, state beneficiary, desired end, situation, horizon, premises
and constraints. A shared frame can apply to the whole record; identify
exceptions per expression. Record only relevant lenses actually used.
A changed question/frame names its predecessor and meaningful delta.

## Candidate expressions

### C1

**Label:** a concise description.

**Expression:** retain the authored expression or clearly label a paraphrase.
Name its producing inquiry, source location and question; shared context may
be declared above. Keep an optional known `poss:`/`arch:` identity separate.

**Meaning and difference:** explain the consequential change in end,
beneficiary, mechanism, premise, scope or truth conditions when assessable.

**Uncertainty:** preserve missing dimensions, assumptions, contradictory
evidence and questions worth further inquiry. An incomplete expression can
stop here without a value or architecture claim.

**Transformation account, when useful:** identify attributed inputs, asserted
change and output. This is an explanation, not a verified cognitive trace.

## Relationships and judgments

### J1

Name the operand(s), criterion, comparison corpus/revision, assessor/date,
judgment, evidence and material uncertainty. A later overlap/grouping judgment
preserves original expressions and historical dispositions. No relationship
is assessed merely because two entries are adjacent.

## Open territory

Identify consequential missing dimensions, competing interpretations and
unexamined sources. Separate NOT_ASSESSED from a supported absence. State
what another lens or source could change, without a required lens quota.

## Completion and possible continuation

State the substantive result and reason to stop. A justified no-new-expression
result is valid. Name any warranted further inquiry and its scope; a
recommendation does not execute the next stage or authorize implementation.
Record actual persistence and any existing receipt pointer.
