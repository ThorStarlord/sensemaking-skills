# Fog Types

To route correctly, first identify what kind of "fog" we are dealing with.

| Fog Type | Description | Primary Ecosystem |
| :--- | :--- | :--- |
| **Product Fog** | Unclear customer pain, persona, or value prop. | Product Manager Skills |
| **Architecture Fog** | Unclear system shape, core objects, or boundaries. | Matt Skills / Interface Skills |
| **Contract Fog** | Unclear validation rules, deterministic behavior, or TDD. | Matt Skills (TDD) / Interface Skills |
| **Drift Fog** | Implementation is straying from the spec or docs. | Interface Skills (Redline) |
| **Knowledge Fog** | Missing domain information (e.g., "How does n8n handle X?"). | Research / Sensemaker |
| **Routing Fog** | Unclear which doc or skill should own a new idea. | Sensemaker (Boundary Finder) |
| **Documentation Fog** | Conflict between new ideas and existing ARCHITECTURE.md/ADRs. | Matt Skills (Grill-with-docs) |
