# ready-for-agent/

Agent briefs staged for hand-off to a coding agent (the `ready-for-agent`
triage state; see `docs/agents/triage-labels.md`).

- `brief-v1-release.md` - V1 release handoff audit.
- `brief-final-verification.md` - final verification brief.

**Status:** historical V1-era briefs. Check the issue tracker
(`docs/agents/issue-tracker.md`) before acting on one; a brief here is not
current authorization.
